# Valorant Tournament Platform CIS

Платформа для проведения любительских и полупрофессиональных турниров по Valorant в СНГ.

> **⚠️ ВНИМАНИЕ**
> Полная документация, спецификация, архитектура и инструкции для разработчиков находятся в файле **[spec.md](./spec.md)**.
> 
> Пожалуйста, обращайтесь к `spec.md` за актуальной информацией о проекте.
> **ВАЖНО:** При внесении изменений в проект, `spec.md` должен быть обновлен.

## Быстрый старт

```bash
npm install
npm run dev
```

Подробнее см. в [spec.md](./spec.md).
