# Valorant Tournament Platform CIS

Специализированная социальная экосистема для игроков в Valorant.
Платформа объединяет функции социальной сети, автоматизированной турнирной площадки и инструментов для поиска тиммейтов (LFG) в едином пространстве.

**Ключевые возможности:**
* **Web-версия:** Быстрый доступ к профилям, турнирным сеткам и новостям с любого устройства.
* **Desktop-клиент:** Расширенная версия с автоматизацией турнирных действий и интеграцией с игровым клиентом (в рамках правил Riot).
